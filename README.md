# NSDI25-VEP-535

This is the repository for "[#535 VEP: A Two-stage Verification Toolchain for Full eBPF Programmability](https://nsdi25fall.usenix.hotcrp.com/paper/535/)".

The folder ``VEP benchmark`` contains all the example code in Table 4 and 5 in the paper. ``VEP benchmark result.xlsx`` shows the results.  ``VEP.tar`` is a docker image holding our software.
